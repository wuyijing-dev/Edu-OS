## 🎯 核心概念

### 1. 什么是中断？

**中断（Interrupt）** 是CPU暂停当前执行的程序，转而执行特定处理程序的机制。

```
正常程序执行流程：
指令1 → 指令2 → 指令3 → 指令4 → ...

中断发生时：
指令1 → 指令2 → [中断] → 保存现场 → 中断处理程序 → 恢复现场 → 指令3 → ...
```

### 2. 中断的分类

#### A. 按来源分类

| 类型 | 来源 | 示例 | 中断号 |
|------|------|------|--------|
| **内部中断（异常）** | CPU内部 | 除零错误、缺页异常 | 0-31 |
| **外部中断（硬件中断）** | 外部设备 | 定时器、键盘、网卡 | 32-255 |
| **软件中断** | 软件触发 | 系统调用（int 0x80） | 可自定义 |

#### B. 按处理优先级

```
不可屏蔽中断(NMI)  ← 最高优先级，无法屏蔽
    ↓
可屏蔽硬件中断(INTR) ← 可通过IF标志屏蔽
    ↓
软件中断            ← 通过INT指令触发
```

### 3. x86中断向量表

x86处理器支持256个中断向量（0-255）：

```
中断号    类型                 说明
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
0         除零异常(#DE)        除法错误
1         调试异常(#DB)        单步调试
2         NMI                  不可屏蔽中断
3         断点异常(#BP)        INT3指令
4         溢出异常(#OF)        INTO指令
5         边界检查(#BR)        BOUND指令
6         无效操作码(#UD)      非法指令
7         设备不可用(#NM)      FPU不存在
8         双重故障(#DF)        异常处理中出现异常
9         协处理器段越界       （保留）
10        无效TSS(#TS)         任务状态段错误
11        段不存在(#NP)        段不在内存
12        栈段故障(#SS)        栈操作错误
13        通用保护故障(#GP)    保护模式违规
14        缺页异常(#PF)        页不在内存
15        保留                 Intel保留
16        浮点错误(#MF)        x87 FPU错误
17        对齐检查(#AC)        未对齐访问
18        机器检查(#MC)        硬件错误
19        SIMD浮点(#XM)        SSE/AVX错误
20-31     保留                 Intel保留
32-255    用户定义             硬件中断/系统调用
```

### 4. 硬件中断（IRQ）映射

8259A PIC管理16个硬件中断（IRQ0-IRQ15）：

```
IRQ号   默认向量   重映射向量   设备
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
IRQ0    8         32          PIT定时器（系统时钟）
IRQ1    9         33          键盘控制器
IRQ2    10        34          级联到从PIC
IRQ3    11        35          串口2(COM2)
IRQ4    12        36          串口1(COM1)
IRQ5    13        37          并口2/声卡
IRQ6    14        38          软盘控制器
IRQ7    15        39          并口1(LPT1)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
IRQ8    0x70      40          实时时钟(RTC)
IRQ9    0x71      41          ACPI
IRQ10   0x72      42          可用
IRQ11   0x73      43          可用
IRQ12   0x74      44          PS/2鼠标
IRQ13   0x75      45          数学协处理器
IRQ14   0x76      46          主IDE控制器
IRQ15   0x77      47          从IDE控制器
```

**为什么要重映射？**
- CPU异常占用0-31号中断
- PIC默认使用8-15号（与异常冲突）
- 必须重映射到32+号避免冲突

## 🏗️ IDT（中断描述符表）

### 1. IDT结构

IDT是一个包含256个门描述符的数组，每个描述符8字节：

```
内存布局：
┌──────────────────────────────────────────┐
│  IDT Entry 0   (8 bytes)  - 除零异常     │
├──────────────────────────────────────────┤
│  IDT Entry 1   (8 bytes)  - 调试异常     │
├──────────────────────────────────────────┤
│  ...                                     │
├──────────────────────────────────────────┤
│  IDT Entry 32  (8 bytes)  - IRQ0 定时器  │
├──────────────────────────────────────────┤
│  IDT Entry 33  (8 bytes)  - IRQ1 键盘    │
├──────────────────────────────────────────┤
│  ...                                     │
├──────────────────────────────────────────┤
│  IDT Entry 255 (8 bytes)                 │
└──────────────────────────────────────────┘
```

### 2. 中断门描述符格式

每个IDT条目（8字节）的位域结构：

```
63                                                                  32
┌────────────────────────────────────────────────────────────────────┐
│                    Offset 31:16                                    │
└────────────────────────────────────────────────────────────────────┘

31     23       15       7       0
┌───────┬───────┬────────┬────────┐
│ Offset│   P   │  Type  │ Offset │
│ 15:0  │ DPL 0 │  Flags │ 31:16  │
│       │       │        │        │
└───────┴───────┴────────┴────────┘

字段说明：
- Offset 31:0   : 中断处理程序地址（分为两部分）
- Segment Select: 代码段选择子（通常是内核代码段）
- P             : 存在位（1=有效，0=无效）
- DPL           : 描述符特权级（0=内核，3=用户）
- Type          : 门类型（0xE=中断门，0xF=陷阱门）
- 0             : 保留位
```

### 3. 中断门 vs 陷阱门

| 特性 | 中断门(0xE) | 陷阱门(0xF) |
|------|-------------|-------------|
| IF标志 | 自动清除（禁止中断） | 保持不变 |
| 用途 | 硬件中断处理 | 异常处理、系统调用 |
| 可重入 | 否 | 是 |

**生产建议**：
- 硬件中断使用中断门（防止嵌套中断）
- 异常使用陷阱门（允许调试）
- 系统调用使用陷阱门（允许中断）

## 🔧 8259A PIC编程

### 1. PIC架构

```
         CPU
          │
          │ INTR
          ↓
    ┌──────────┐
    │ 主PIC    │ IRQ0-7
    │ (Master) │
    └──────────┘
          │ IRQ2 (级联)
          ↓
    ┌──────────┐
    │ 从PIC    │ IRQ8-15
    │ (Slave)  │
    └──────────┘
```

### 2. PIC端口地址

| PIC | 命令端口 | 数据端口 |
|-----|---------|---------|
| 主PIC | 0x20 | 0x21 |
| 从PIC | 0xA0 | 0xA1 |

### 3. PIC初始化流程（ICW1-4）

```
初始化命令字(ICW)：
ICW1: 启动初始化
ICW2: 设置中断向量偏移
ICW3: 设置级联
ICW4: 设置工作模式

操作命令字(OCW)：
OCW1: 中断屏蔽寄存器(IMR)
OCW2: EOI命令
OCW3: 读取寄存器
```

### 4. EOI（End of Interrupt）

中断处理完成后**必须**发送EOI信号：

```c
// 主PIC中断
outb(0x20, 0x20);

// 从PIC中断（需要同时发送给主从PIC）
outb(0xA0, 0x20);  // 从PIC
outb(0x20, 0x20);  // 主PIC
```

**忘记发送EOI的后果**：
- PIC认为中断仍在处理中
- 同级或低级中断被阻塞
- 系统停止响应该设备

## 🎨 中断处理流程

### 完整处理流程图

```
1. 硬件事件发生
   ↓
2. 设备向PIC发送IRQ信号
   ↓
3. PIC向CPU发送INTR信号
   ↓
4. CPU完成当前指令
   ↓
5. CPU检查IF标志（中断是否允许）
   ↓
6. CPU从PIC获取中断向量号
   ↓
7. CPU查找IDT表项
   ↓
8. CPU自动保存：
   - SS, ESP (如果特权级改变)
   - EFLAGS
   - CS, EIP
   - Error Code (某些异常)
   ↓
9. CPU跳转到ISR地址
   ↓
10. ISR保存所有寄存器（手动）
    - EAX, EBX, ECX, EDX
    - ESI, EDI, EBP
    - DS, ES, FS, GS
    ↓
11. 调用C语言处理函数
    ↓
12. C函数处理中断逻辑
    ↓
13. 发送EOI到PIC
    ↓
14. 恢复所有寄存器
    ↓
15. 执行IRET指令
    ↓
16. CPU自动恢复：
    - EIP, CS
    - EFLAGS
    - ESP, SS (如果特权级改变)
    ↓
17. 返回到被中断的代码
```

### 中断栈帧结构

```
中断发生时CPU自动压栈：
┌─────────────┐ ← ESP（进入ISR时）
│ [Error Code]│   (仅某些异常)
├─────────────┤
│    EIP      │   返回地址
├─────────────┤
│    CS       │   代码段
├─────────────┤
│  EFLAGS     │   标志寄存器
├─────────────┤
│    ESP      │   (特权级改变时)
├─────────────┤
│    SS       │   (特权级改变时)
└─────────────┘

ISR手动保存：
┌─────────────┐ ← ESP（调用C函数前）
│    GS       │
├─────────────┤
│    FS       │
├─────────────┤
│    ES       │
├─────────────┤
│    DS       │
├─────────────┤
│    EBP      │
├─────────────┤
│    EDI      │
├─────────────┤
│    ESI      │
├─────────────┤
│    EDX      │
├─────────────┤
│    ECX      │
├─────────────┤
│    EBX      │
├─────────────┤
│    EAX      │
└─────────────┘
```

## 💻 代码实现详解

### 1. 数据结构定义

```c
// IDT门描述符
struct idt_entry {
    uint16_t offset_low;    // 偏移地址低16位
    uint16_t selector;      // 代码段选择子
    uint8_t  zero;          // 保留（必须为0）
    uint8_t  type_attr;     // 类型和属性
    uint16_t offset_high;   // 偏移地址高16位
} __attribute__((packed));

// IDT指针（用于LIDT指令）
struct idt_ptr {
    uint16_t limit;         // IDT大小-1
    uint32_t base;          // IDT基址
} __attribute__((packed));

// 中断帧（寄存器状态）
struct interrupt_frame {
    // 手动保存的寄存器
    uint32_t gs, fs, es, ds;
    uint32_t edi, esi, ebp, esp;
    uint32_t ebx, edx, ecx, eax;
    
    // 中断号和错误码
    uint32_t int_no, err_code;
    
    // CPU自动保存的寄存器
    uint32_t eip, cs, eflags;
    uint32_t user_esp, ss;  // 特权级改变时
};
```

### 2. 设置IDT条目

```c
static void idt_set_gate(uint8_t num, uint32_t handler, 
                         uint16_t selector, uint8_t flags)
{
    idt[num].offset_low  = handler & 0xFFFF;
    idt[num].offset_high = (handler >> 16) & 0xFFFF;
    idt[num].selector    = selector;
    idt[num].zero        = 0;
    idt[num].type_attr   = flags;
}

// 使用示例
idt_set_gate(0, (uint32_t)isr0, 0x08, 0x8E);
//            ↑        ↑          ↑      ↑
//         中断号   处理函数地址  代码段  属性
//                                     (P=1,DPL=0,Type=0xE)
```

### 3. 中断服务程序（ISR）汇编模板

```nasm
; 无错误码的异常
isr0:
    push 0          ; 压入虚拟错误码
    push 0          ; 压入中断号
    jmp isr_common

; 有错误码的异常
isr13:
    ; CPU已经压入错误码
    push 13         ; 压入中断号
    jmp isr_common

; 公共ISR处理
isr_common:
    ; 保存所有寄存器
    pusha           ; 保存EAX,ECX,EDX,EBX,ESP,EBP,ESI,EDI
    
    push ds
    push es
    push fs
    push gs
    
    ; 加载内核数据段
    mov ax, 0x10
    mov ds, ax
    mov es, ax
    mov fs, ax
    mov gs, ax
    
    ; 调用C处理函数
    push esp        ; 传递中断帧指针
    call interrupt_handler
    add esp, 4
    
    ; 恢复所有寄存器
    pop gs
    pop fs
    pop es
    pop ds
    
    popa            ; 恢复通用寄存器
    add esp, 8      ; 清除中断号和错误码
    
    iret            ; 中断返回
```

### 4. C语言中断处理器

```c
void interrupt_handler(struct interrupt_frame *frame)
{
    // 异常处理
    if (frame->int_no < 32) {
        exception_handler(frame);
        return;
    }
    
    // 硬件中断处理
    if (frame->int_no >= 32 && frame->int_no < 48) {
        irq_handler(frame->int_no - 32, frame);
        
        // 发送EOI
        if (frame->int_no >= 40) {
            outb(0xA0, 0x20);  // 从PIC
        }
        outb(0x20, 0x20);      // 主PIC
        
        return;
    }
}
```

## 🚨 常见异常处理

### 1. 除零异常(#DE, 0)

```c
void handle_divide_error(struct interrupt_frame *frame)
{
    kprintf("EXCEPTION: Divide by Zero\n");
    kprintf("  EIP: 0x%08x\n", frame->eip);
    kprintf("  CS:  0x%04x\n", frame->cs);
    
    // 生产环境：终止进程
    if (current_process) {
        kill_process(current_process->pid, SIGFPE);
    } else {
        panic("Divide by zero in kernel!");
    }
}
```

### 2. 通用保护故障(#GP, 13)

最常见的异常，原因包括：
- 访问空指针
- 段权限违规
- 无效的段选择子
- 堆栈溢出

```c
void handle_general_protection(struct interrupt_frame *frame)
{
    kprintf("EXCEPTION: General Protection Fault\n");
    kprintf("  Error Code: 0x%08x\n", frame->err_code);
    
    // 解析错误码
    if (frame->err_code & 0x1) {
        kprintf("  External event\n");
    } else {
        kprintf("  Internal event\n");
    }
    
    uint16_t selector = frame->err_code >> 3;
    kprintf("  Selector: 0x%04x\n", selector);
    
    // 打印寄存器状态
    print_registers(frame);
    
    // 终止进程或内核崩溃
    panic("General Protection Fault");
}
```

### 3. 缺页异常(#PF, 14)

```c
void handle_page_fault(struct interrupt_frame *frame)
{
    // 读取CR2寄存器（故障地址）
    uint32_t fault_addr;
    asm volatile("mov %%cr2, %0" : "=r"(fault_addr));
    
    // 解析错误码
    int present  = frame->err_code & 0x1;  // 页不存在
    int write    = frame->err_code & 0x2;  // 写操作
    int user     = frame->err_code & 0x4;  // 用户模式
    int reserved = frame->err_code & 0x8;  // 保留位被设置
    int ifetch   = frame->err_code & 0x10; // 指令取指
    
    kprintf("Page Fault at 0x%08x\n", fault_addr);
    kprintf("  Cause: %s %s in %s mode\n",
            write ? "Write" : "Read",
            present ? "protection violation" : "non-present page",
            user ? "user" : "kernel");
    
    // 生产环境：调用内存管理器处理
    if (handle_page_fault_mm(fault_addr, frame->err_code)) {
        return;  // 成功处理
    }
    
    // 无法处理，终止进程
    panic("Page fault");
}
```

## ⏱️ 定时器中断（PIT 8253/8254）

### 1. PIT编程

```c
// PIT端口
#define PIT_CHANNEL0    0x40
#define PIT_COMMAND     0x43

// PIT频率
#define PIT_FREQUENCY   1193182  // Hz

void timer_init(uint32_t frequency)
{
    // 计算分频值
    uint32_t divisor = PIT_FREQUENCY / frequency;
    
    // 配置PIT
    // 命令：通道0，模式3（方波），二进制
    outb(PIT_COMMAND, 0x36);
    
    // 发送分频值（低字节+高字节）
    outb(PIT_CHANNEL0, divisor & 0xFF);
    outb(PIT_CHANNEL0, (divisor >> 8) & 0xFF);
    
    // 注册IRQ0处理函数
    irq_install_handler(0, timer_handler);
    
    kprintf("Timer initialized: %d Hz\n", frequency);
}
```

### 2. 定时器处理函数

```c
static volatile uint64_t system_ticks = 0;

void timer_handler(struct interrupt_frame *frame)
{
    system_ticks++;
    
    // 每秒打印一次（假设100Hz）
    if (system_ticks % 100 == 0) {
        kprintf("Uptime: %llu seconds\n", system_ticks / 100);
    }
    
    // 生产环境：进程调度
    if (scheduler_enabled) {
        schedule();  // 进程切换
    }
}
```

## 🛡️ 生产级注意事项

### 1. 中断安全性

```c
// 临界区保护
void critical_section()
{
    cli();  // 禁用中断
    
    // 访问共享数据
    global_counter++;
    
    sti();  // 恢复中断
}

// 更安全的方法：保存/恢复中断状态
uint32_t flags = save_irq_disable();
// 临界区代码
restore_irq(flags);
```

### 2. 中断嵌套控制

```c
// 禁止中断嵌套（使用中断门）
idt_set_gate(32, handler, 0x08, 0x8E);  // 中断门

// 允许中断嵌套（使用陷阱门 + 手动sti）
idt_set_gate(32, handler, 0x08, 0x8F);  // 陷阱门
// 在处理函数中：
void handler() {
    sti();  // 手动允许中断
    // 处理代码
    cli();
}
```

// 最小化中断处理时间
void fast_irq_handler()
{
    // 1. 快速读取硬件状态
    uint32_t status = read_device_status();
    
    // 2. 清除中断请求

### 4. 错误处理

```c
void robust_interrupt_handler(struct interrupt_frame *frame)
{
    // 验证中断号
    if (frame->int_no >= MAX_INTERRUPTS) {
        kprintf("Invalid interrupt: %d\n", frame->int_no);
        return;
    }
    
    // 检查处理函数是否注册
    if (!irq_handlers[frame->int_no]) {
        kprintf("Unhandled interrupt: %d\n", frame->int_no);
        // 仍然需要发送EOI
        send_eoi(frame->int_no);
        return;
    }
    
    // 调用注册的处理函数
    irq_handlers[frame->int_no](frame);
}
```
