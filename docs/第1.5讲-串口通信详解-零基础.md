## 📖 第一课：认识串口

### 1.1 什么是串口？

**串口（Serial Port）** = 串行通信端口

**生活中的串口：**
```
老式鼠标的圆形接口  → COM 端口
调制解调器连接线    → COM 端口
工业设备通信线      → RS-232
```

**在计算机中：**
```
串口就像一根"电话线"：
  一端：你的 CPU
  另一端：外部设备（调试电脑、终端等）
  
通过它可以：
  → 发送数据给外部
  → 接收外部的数据
```

---

### 1.2 为什么操作系统需要串口？

**问题：VGA 不够用吗？**

VGA 的限制：
- 只能显示，不能输入（需要配合键盘）
- 只有 2000 个字符（80×25）
- 滚动后历史信息丢失
- 无法保存日志

**串口的优势：**

```
调试场景：
┌─────────────────┐       串口连接      ┌──────────────────┐
│   开发板/虚拟机  │ ←──────────────→ │   你的开发电脑    │
│   (运行 EduOS)   │                   │   (保存日志)      │
└─────────────────┘                   └──────────────────┘

EduOS 输出：
  kprintf("Debug: value=%d\n", x);
  
你的电脑看到：
  Debug: value=42
  Debug: value=43
  ...
  
  可以：
    - 无限滚动
    - 复制粘贴
    - 保存到文件
    - 搜索内容
```

**实际应用：**

```c
// 在 QEMU 中运行时
qemu -serial stdio  // 串口输出到终端

// 内核输出
serial_puts(COM1, "[KERNEL] Booting...\n");
serial_puts(COM1, "[KERNEL] Memory: 128MB\n");

// 你的终端立即看到：
[KERNEL] Booting...
[KERNEL] Memory: 128MB

// 不占用屏幕空间！
```

### 1.3 串口 vs VGA 对比

| 特性 | VGA | 串口 |
|------|-----|------|
| 显示方式 | 屏幕 | 终端/文件 |
| 容量 | 2000字符 | 无限 |
| 历史记录 | 滚动丢失 | 全部保留 |
| 交互 | 需要键盘 | 双向通信 |
| 速度 | 快 | 较慢 |
| 用途 | 用户界面 | 调试输出 |
| 初始化 | 简单 | 复杂 |

**最佳实践：**
```c
// 同时使用！
void kprintf(const char *fmt, ...)
{
    char buf[1024];
    format_string(buf, fmt, args);
    
    vga_puts(buf);      // 显示在屏幕上
    serial_puts(COM1, buf);  // 同时输出到串口
}
```

## 📖 第二课：串口通信原理

### 2.1 什么是"串行"？

**串行（Serial）vs 并行（Parallel）：**

```
并行通信（8位数据）：
  时间 →
  D0 ─────────────●●●●────────
  D1 ─────────────●──●────────
  D2 ─────────────●●─●────────
  D3 ─────────────●──●────────
  D4 ─────────────●●●●────────
  ...
  
  一次传输 8 位 = 1 字节
  需要 8 根线

串行通信（1位数据）：
  时间 →
  TX ───●─●─●─●─●─●─●─●───
        1 0 1 0 1 1 0 0
        └─┴─┴─┴─┴─┴─┴─┴─ 一个字节
  
  一次传输 1 位，连续发送 8 次
  只需要 1 根线（+ 1 根地线）
```

**串行通信的优势：**
- ✅ 线缆简单（只需 2-3 根线）
- ✅ 成本低
- ✅ 传输距离远（可达几十米）
- ✅ 抗干扰强

**缺点：**
- ⚠️ 速度较慢（一次只传 1 位）

---

### 2.2 串口通信的数据格式

**一个字节的传输：**

```
起始位  数据位（8位）       停止位
  ↓     ↓↓↓↓↓↓↓↓         ↓
──┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌───
  └─┘ └─┘ └─┘ └─┘ └─┘ └─┘
  0   D0  D1  D2  ...  D7  1

空闲状态：高电平（1）
起始位  ：低电平（0）← 告诉接收方"数据来了"
数据位  ：8 位数据（从 LSB 到 MSB）
停止位  ：高电平（1）← 结束标记
```

**示例：发送字符 'A' (0x41 = 0100 0001)**

```
时间 →
     起始 D0 D1 D2 D3 D4 D5 D6 D7 停止
     ↓    ↓  ↓  ↓  ↓  ↓  ↓  ↓  ↓  ↓
  ───┐  ┌──┐  ┌──┐  ┌─────┐  ┌───
     └──┘  └──┘  └──┘     └──┘
     0  1  0  0  0  0  1  0  1  1
        ↑              ↑     ↑
       D0              D6    D7
       
发送顺序：从低位到高位
  0100 0001 → 发送为 1 0 0 0 0 0 1 0
```

---

### 2.3 波特率（Baud Rate）

**波特率 = 每秒传输的符号数**

**常见波特率：**
```
9600 bps   - 每秒 9600 位 ≈ 1200 字节/秒
19200 bps  - 每秒 19200 位 ≈ 2400 字节/秒
38400 bps  - 较快
57600 bps  - 快
115200 bps - 最快（常用）≈ 14400 字节/秒
```

**双方必须使用相同的波特率！**

```
发送方：115200 bps
接收方：9600 bps

结果：
  发送方发得太快
  → 接收方跟不上
  → 数据错乱
  → 乱码！
```

## 📖 第三课：UART 芯片和寄存器

### 3.1 什么是 UART？

**UART = Universal Asynchronous Receiver-Transmitter**  
（通用异步收发器）

```
UART 芯片的作用：
  CPU 并行数据 → UART → 串行数据 → 外部设备
  
  CPU 给 UART：0x41（一次给 8 位）
  UART 发送： 一位一位发出去
```

**PC 上的 UART：16550 芯片**

这个芯片有多个寄存器，通过 I/O 端口访问。

### 3.2 COM 端口地址

**PC 上通常有 4 个 COM 端口：**

```c
#define COM1    0x3F8    // 常用，连接串口1
#define COM2    0x2F8    // 常用，连接串口2
#define COM3    0x3E8    // 少用
#define COM4    0x2E8    // 少用
```

**每个 COM 端口有 8 个寄存器：**

| 偏移 | 寄存器 | 说明 |
|------|--------|------|
| +0 | 数据寄存器 | 读写数据（DLAB=0时） |
| +0 | 除数低字节 | 设置波特率（DLAB=1时） |
| +1 | 中断使能 | 控制中断（DLAB=0时） |
| +1 | 除数高字节 | 设置波特率（DLAB=1时） |
| +2 | FIFO 控制 | 控制缓冲区 |
| +3 | 线路控制 | 数据格式、DLAB |
| +4 | 调制解调器控制 | 握手信号 |
| +5 | 线路状态 | 发送/接收状态 |
| +6 | 调制解调器状态 | 连接状态 |
| +7 | Scratch | 测试用 |

**示例：访问 COM1 的数据寄存器**

```c
// 写入数据
outb(COM1 + 0, 'A');  // COM1 + SERIAL_DATA

// 读取数据  
char c = inb(COM1 + 0);
```

---

### 3.3 关键寄存器详解

#### 线路控制寄存器（LCR, +3）

```
Bit 7:   DLAB  - 除数锁存访问位
Bit 6:   Break - 发送中断
Bit 5-3: 校验  - 无/奇/偶校验
Bit 2:   停止位 - 1位或2位
Bit 1-0: 数据位 - 5/6/7/8位

常用值：
  0x03 = 0000 0011  → 8位数据，1位停止，无校验
  0x80 = 1000 0000  → 启用 DLAB（访问波特率寄存器）
```

**DLAB 的作用：**

```
偏移 +0 和 +1 有两种用途：

DLAB = 0（默认）：
  +0 → 数据寄存器（读写数据）
  +1 → 中断使能寄存器
  
DLAB = 1：
  +0 → 波特率除数低字节
  +1 → 波特率除数高字节

所以设置波特率时：
  1. 设置 DLAB=1（访问除数寄存器）
  2. 写入波特率
  3. 清除 DLAB=0（恢复正常功能）
```

#### 线路状态寄存器（LSR, +5）

```
Bit 0: DR  - 数据就绪（有数据可读）
Bit 5: THRE - 发送保持寄存器空（可以发送）
Bit 6: TEMT - 发送器空

读取状态：
  uint8_t status = inb(COM1 + 5);
  
  if (status & 0x01) {
      // 有数据可读
      char c = inb(COM1 + 0);
  }
  
  if (status & 0x20) {
      // 可以发送
      outb(COM1 + 0, 'A');
  }
```

## 📖 第四课：串口初始化

### 4.1 初始化流程

初始化串口需要配置多个参数：

```
1. 禁用中断
2. 设置波特率（115200 bps）
3. 设置数据格式（8位数据，1位停止，无校验）
4. 启用 FIFO 缓冲区
5. 设置调制解调器控制
6. 测试串口是否正常
```

### 4.2 完整的初始化代码

让我们一步步实现（对应 `kernel/serial.c`）：

```c
void serial_init(uint16_t port)
{
    // 步骤1：禁用所有中断
    outb(port + 1, 0x00);
    
    // 步骤2：启用 DLAB（访问波特率寄存器）
    outb(port + 3, 0x80);
    
    // 步骤3：设置波特率 = 115200（除数=1）
    outb(port + 0, 0x01);  // 除数低字节
    outb(port + 1, 0x00);  // 除数高字节
    
    // 步骤4：设置数据格式（8位，1停止，无校验）
    outb(port + 3, 0x03);
    
    // 步骤5：启用 FIFO，清空缓冲区
    outb(port + 2, 0xC7);
    
    // 步骤6：设置调制解调器控制（RTS/DTR）
    outb(port + 4, 0x0B);
    
    // 步骤7：测试串口（回环测试）
    outb(port + 4, 0x1E);  // 启用回环模式
    outb(port + 0, 0xAE);  // 发送测试字节
    
    if (inb(port + 0) != 0xAE) {
        // 串口有问题
        return;
    }
    
    // 步骤8：禁用回环，启用正常操作
    outb(port + 4, 0x0F);
}
```

### 4.3 逐步详解

**步骤1：禁用中断**

```c
outb(port + 1, 0x00);

为什么？
  初始化时不需要中断
  避免未初始化的中断干扰
  
  port + 1 = 中断使能寄存器（IER）
  0x00 = 所有中断禁用
```

**步骤2-3：设置波特率**

```c
outb(port + 3, 0x80);  // DLAB = 1
outb(port + 0, 0x01);  // 除数 = 1
outb(port + 1, 0x00);

计算：
  UART 基础频率 = 115200 Hz
  波特率 = 115200 / 除数
  
  除数 = 1 → 波特率 = 115200 bps（最快）
  除数 = 2 → 波特率 = 57600 bps
  除数 = 12 → 波特率 = 9600 bps
```

**步骤4：数据格式**

```c
outb(port + 3, 0x03);

0x03 = 0000 0011
  Bit 7: DLAB = 0  → 恢复正常模式
  Bit 1-0: 11      → 8 位数据
  其他位: 0        → 1 停止位，无校验
```

**步骤5：FIFO 缓冲区**

```c
outb(port + 2, 0xC7);

0xC7 = 1100 0111
  Bit 7-6: 11 → 触发级别（14字节）
  Bit 2:   1  → 清空接收 FIFO
  Bit 1:   1  → 清空发送 FIFO
  Bit 0:   1  → 启用 FIFO

FIFO 的作用：
  缓冲区，可以存储多个字节
  → CPU 不用每个字节都立即处理
  → 提高效率
```

**步骤7-8：回环测试**

```c
outb(port + 4, 0x1E);  // 回环模式
outb(port + 0, 0xAE);  // 发送测试字节
if (inb(port + 0) != 0xAE) {
    // 失败
}

回环模式（Loopback）：
  TX 直接连到 RX
  → 发送的数据自己收到
  → 用来测试硬件是否正常
  
  0x1E = 0001 1110
    Bit 4: 1 → 启用回环
```

## 📖 第五课：发送数据

### 5.1 发送单个字符

**基本思路：**

```
1. 等待发送缓冲区空
2. 写入字符到数据寄存器
3. UART 自动发送
```

**实现代码：**

```c
void serial_putc(uint16_t port, char c)
{
    // 等待发送器就绪
    while (!serial_transmit_empty(port))
        ;  // 忙等待
    
    // 写入数据
    outb(port + 0, c);
}

// 检查发送器是否空
int serial_transmit_empty(uint16_t port)
{
    return inb(port + 5) & 0x20;
    //     线路状态寄存器  ↑
    //                  Bit 5 = THRE（发送保持寄存器空）
}
```

**工作流程：**

```
调用 serial_putc(COM1, 'A')
  ↓
检查 LSR Bit 5
  ↓
如果 = 0（忙）→ 等待
如果 = 1（空）→ 继续
  ↓
写入 'A' 到数据寄存器
  ↓
UART 硬件自动：
  生成起始位
  → 发送 8 位数据
  → 发送停止位
  ↓
完成！
```

### 5.2 发送字符串

```c
void serial_puts(uint16_t port, const char *str)
{
    while (*str) {
        serial_putc(port, *str++);
    }
}

// 使用
serial_puts(COM1, "Hello, Serial!\n");
```

**处理换行：**

```c
void serial_putc_nl(uint16_t port, char c)
{
    if (c == '\n') {
        serial_putc(port, '\r');  // 先发送回车
        serial_putc(port, '\n');  // 再发送换行
    } else {
        serial_putc(port, c);
    }
}

为什么要 \r\n？
  Windows/串口终端习惯：
    \r = 回车（回到行首）
    \n = 换行（移到下一行）
    
  只有 \n：
    下一行，但不回行首
    → 输出变成阶梯状
```

## 📖 第六课：接收数据

### 6.1 接收单个字符

```c
char serial_getc(uint16_t port)
{
    // 等待数据就绪
    while (!serial_received(port))
        ;
    
    // 读取数据
    return inb(port + 0);
}

// 检查是否有数据
int serial_received(uint16_t port)
{
    return inb(port + 5) & 0x01;
    //     线路状态寄存器  ↑
    //                  Bit 0 = DR（数据就绪）
}
```

### 6.2 非阻塞接收

```c
// 如果有数据就读取，否则返回 -1
int serial_getc_nowait(uint16_t port)
{
    if (serial_received(port)) {
        return inb(port + 0);
    }
    return -1;  // 没有数据
}

// 使用
int c = serial_getc_nowait(COM1);
if (c >= 0) {
    kprintf("Received: %c\n", (char)c);
}
```

### 6.3 简单的命令行

```c
void serial_read_line(uint16_t port, char *buffer, int max_len)
{
    int pos = 0;
    
    while (pos < max_len - 1) {
        char c = serial_getc(port);  // 阻塞等待
        
        if (c == '\r' || c == '\n') {
            buffer[pos] = '\0';
            break;
        } else if (c == '\b' && pos > 0) {
            // 退格
            pos--;
            serial_puts(port, "\b \b");  // 回显
        } else if (c >= 32 && c < 127) {
            // 可打印字符
            buffer[pos++] = c;
            serial_putc(port, c);  // 回显
        }
    }
    
    buffer[pos] = '\0';
}

// 使用
char input[256];
serial_puts(COM1, "Enter command: ");
serial_read_line(COM1, input, sizeof(input));
kprintf("You entered: %s\n", input);
```

### 7.3 双向调试

**远程控制内核：**

```c
void debug_console(void)
{
    serial_puts(COM1, "\nEduOS Debug Console\n");
    serial_puts(COM1, "> ");
    
    while (1) {
        char cmd[256];
        serial_read_line(COM1, cmd, sizeof(cmd));
        
        if (strcmp(cmd, "help") == 0) {
            serial_puts(COM1, "Commands: help, reboot, info\n");
        } else if (strcmp(cmd, "reboot") == 0) {
            serial_puts(COM1, "Rebooting...\n");

        } else if (strcmp(cmd, "info") == 0) {
            serial_puts(COM1, "EduOS v0.9.0\n");
        }
        
        serial_puts(COM1, "> ");
    }
}
```

## 🧪 实战练习

### 练习1：串口回显程序

```c
// 读取输入并回显
void serial_echo(void)
{
    serial_puts(COM1, "Echo mode. Type something:\n");
    
    while (1) {
        char c = serial_getc(COM1);
        serial_putc(COM1, c);  // 回显
        
        if (c == 'q') {
            serial_puts(COM1, "\nQuit\n");
            break;
        }
    }
}
```

### 练习2：十六进制转储

```c
void serial_hexdump(void *addr, int length)
{
    uint8_t *data = (uint8_t*)addr;
    
    for (int i = 0; i < length; i += 16) {
        // 打印地址
        char buf[100];
        snprintf(buf, sizeof(buf), "%08X: ", (uint32_t)&data[i]);
        serial_puts(COM1, buf);
        
        // 打印16字节的十六进制
        for (int j = 0; j < 16 && i + j < length; j++) {
            snprintf(buf, sizeof(buf), "%02X ", data[i + j]);
            serial_puts(COM1, buf);
        }
        
        serial_puts(COM1, "\n");
    }
}

// 使用
serial_hexdump((void*)0xB8000, 160);  // 转储显存前160字节
```

### 练习3：性能测试

```c
void serial_benchmark(void)
{
    const int COUNT = 1000;
    
    serial_puts(COM1, "Sending 1000 bytes...\n");
    
    uint64_t start = timer_get_ticks();
    
    for (int i = 0; i < COUNT; i++) {
        serial_putc(COM1, 'A');
    }
    
    uint64_t end = timer_get_ticks();
    uint64_t elapsed_ms = (end - start) * 1000 / timer_get_frequency();
    
    char buf[100];
    snprintf(buf, sizeof(buf), "Time: %llu ms\n", elapsed_ms);
    serial_puts(COM1, buf);
    
    snprintf(buf, sizeof(buf), "Speed: %llu bytes/sec\n", 
             (COUNT * 1000ULL) / elapsed_ms);
    serial_puts(COM1, buf);
}

// 预期结果（115200 bps）：
// Speed: ~14400 bytes/sec
```

## 🎓 高级话题

### 中断驱动的串口

**问题：轮询浪费 CPU**

```c
// 轮询方式（当前实现）
while (!serial_transmit_empty(port));  // CPU 一直等待

// 中断方式（更高效）
void serial_putc_irq(char c)
{
    buffer[write_pos++] = c;  // 放入缓冲区
    enable_serial_interrupt();  // 启用中断
    // 立即返回，不等待
}

void serial_interrupt_handler(void)
{
    if (write_pos > 0) {
        outb(COM1, buffer[read_pos++]);  // 发送下一个字节
    }
}
```

### 流控制

**硬件流控（RTS/CTS）：**

```c
// 启用硬件流控
void serial_enable_flow_control(uint16_t port)
{
    uint8_t mcr = inb(port + 4);
    mcr |= 0x02;  // RTS
    outb(port + 4, mcr);
}
```

## 🐛 常见问题

### 问题1：串口无输出

**检查清单：**

```c
// 1. 初始化了吗？
serial_init(COM1);  // 必须先初始化

// 2. QEMU 参数正确吗？
// 命令行：-serial stdio

// 3. 端口地址对吗？
serial_puts(COM1, "test");  // 确认是 COM1

// 4. 测试最简单的代码
serial_init(COM1);
while (1) {
    outb(COM1, 'A');
    delay(1000);
}
```

### 问题2：输出乱码

**可能原因：**

```
1. 波特率不匹配
   → 检查除数设置
   → 确认终端波特率设置

2. 数据格式不匹配
   → 检查数据位、停止位、校验位

3. 线路问题
   → 检查连接
   → 尝试回环测试
```

### 问题3：发送很慢

**原因分析：**

```c
// 每次都等待
serial_putc(COM1, 'A');  // 等待
serial_putc(COM1, 'B');  // 等待
serial_putc(COM1, 'C');  // 等待

解决方案：
1. 使用缓冲区批量发送
2. 启用中断驱动
3. 使用 DMA
```
