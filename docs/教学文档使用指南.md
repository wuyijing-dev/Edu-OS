## 💡 学习建议

### 给学生的话

**学习方法：**

1. **先理解概念，再看代码**
   - 不要直接看代码
   - 先读文档理解原理
   - 再对照代码验证

2. **动手实践最重要**
   - 看懂 ≠ 会写
   - 每个例子都要自己敲一遍
   - 改参数，观察效果

3. **遇到问题先调试**
   - 添加 kprintf 输出
   - 检查每个变量的值
   - 理解为什么出错

4. **循序渐进，不要跳跃**
   - 第0讲是基础，必须懂
   - 没学 I/O 端口，VGA 光标部分看不懂
   - 没学中断，系统调用看不懂

**学完第0讲后，你应该能：**

- ✅ 理解 volatile 的作用

**学完第1讲后，你应该能：**
- ✅ 计算任意坐标的显存地址
- ✅ 实现 putchar 和 puts
- ✅ 实现屏幕滚动
- ✅ 控制光标位置

**学完第2讲后，你应该能：**
- ✅ 解释中断的工作流程
- ✅ 设置 IDT 表项
- ✅ 实现定时器中断

**学完第3讲后，你应该能：**
- ✅ 区分异常和中断

## 🎯 常见问题（FAQ）

### Q1：我必须按顺序学吗？

**A：强烈建议按顺序！**

```
第0讲是基础中的基础
  ↓
第1讲用到第0讲的 outb
  ↓
第2讲用到第0讲的 outb 和第1讲的显示
  ↓
环环相扣，跳跃式学习会很困难
```

### Q2：我不懂汇编怎么办？

**A：文档中的汇编都有详细注释**

而且：
- 大部分代码是 C 语言
- 汇编只在必要时使用
- 每条汇编都有解释

### Q3：我没有实际硬件怎么办？

**A：使用 QEMU 虚拟机**

```bash
# 安装 QEMU
sudo apt install qemu-system-x86

# 运行 EduOS
make run

# QEMU 完美模拟所有硬件
```

### Q4：文档和实际代码不一致怎么办？

**A：以代码为准**

- 文档是教学用，简化了某些细节
- 实际代码（kernel/）是完整实现
- 有疑问时，运行代码验证
